      Hướng dẫn triển khai Lab Giám sát (SIEM/Sysmon)
      
                            
      Cấu trúc hạ tầng giám sát an toàn được rút gọn về 3 thành phần cốt lõi của L1 Analyst:
      
                            
                            
      
                                
      
                                    
      📍 Phần 1: Nguồn Log & Phát hiện (Log Sources & Detection)
      
                                    
      
                                        
      Hệ thống giám sát kết hợp Wazuh SIEM làm Manager tập trung và Sysmon (System Monitor) trên Windows client để thu thập hành vi sâu rộng.
      
                                        
        
                                            
      • Wazuh Agent: Cấu hình đẩy logs Windows Security, Application, System, và Sysmon Operational lên server.
        • 
                                            
      • Sysmon: Ghi vết các sự kiện: Process Creation (ID 1), File Creation Time change (ID 2), Network Connect (ID 3), Registry modification (ID 12/13), File Create (ID 11).
        • 
                                        
      
                                    
      
                                
      

                                
      
                                    
      📍 Phần 2: Đánh giá & Phản ứng (Triage & Response Flow)
      
                                    
      
                                        
      Quy trình vận hành chuẩn của L1 Analyst khi tiếp nhận alert:
      
                                        
        
                                            
      1. Alert: Phát hiện hành vi bất thường kích hoạt luật SIEM.
        2. 
                                            
      2. Verify: Kiểm tra log JSON, phân biệt lỗi quản trị hay tấn công.
        3. 
                                            
      3. Scope & Enrich: Tra cứu IP ngoại biên, giải mã command line.
        4. 
                                            
      4. Classify: Phân loại True Positive (TP) / False Positive (FP).
        5. 
                                            
      5. Escalate/Ticket: Tạo ticket, cô lập máy (Active Response) và tinh chỉnh rule (Tuning) nếu là FP.
        6. 
                                        
      
                                    
      
                                
      

                                
      
                                    
      📍 Phần 3: Triển khai Lab & Báo cáo (Lab Deployment & Reporting)
      
                                    
      
                                        
      Các bước dựng Lab nhanh trên môi trường VMware/VirtualBox:
      
                                        
        
                                            
      1. Dựng Wazuh Server chạy bằng Docker Compose trong thư mục deployment/.
        2. 
                                            
      2. Cài đặt Wazuh Agent và Sysmon với file cấu hình chuẩn trong configurations/agent/ lên máy Windows.
        3. 
                                            
      3. Copy các luật phát hiện custom vào local_rules.xml trên Wazuh Manager.
        4. 
                                            
      4. Sử dụng Bảng Triage hoặc Event Generator để kiểm tra tính đúng đắn của luật.
        5.
